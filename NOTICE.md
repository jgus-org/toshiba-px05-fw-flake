| Artifact                                                                                                                                               | Licence & Notifications                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| This flake: the Nix, `extract.py`, `px05-flash.sh`, these documents                                                                                    | [MIT](LICENSE.md)                                                                                                                                                                                                                                                   |
| Dell `SAS-Drive_Firmware_1DJXX_LN_AS10_A00_01.BIN` — the AS10 (`1DJXX`, A00, released 2019-09-17) DUP, the only public source of AS10 for these drives | Toshiba's drive firmware as repackaged by Dell, fetched from `dl.dell.com`. No vendor terms are stated at the URL it is fetched from and none are stated in this repository; this flake declares the fetched file `unfree` rather than naming terms it has not read |
| `AS10_PX05.bin` — the microcode `extract.py` carves from that DUP, validated against a pinned sha256                                                   | The vendor image itself, so the same absence governs it: carving and validating it are ours, the bytes are not                                                                                                                                                      |
| `sg3_utils`, `util-linux`, `coreutils`, `gnugrep` and the rest of the runtime closure                                                                  | As nixpkgs records each one in `meta.license` at the revision this flake locks, where `free` and `redistributable` are separate properties                                                                                                                          |

Nothing vendor-authored is committed here: the DUP is fetched from Dell when `packages.<system>.dup` is built, so evaluating or promoting this repository conveys nothing. Publishing a built `dup` or `firmware` output to a binary cache does convey the vendor image to whoever can read that cache, and the unfree acceptance this flake sets in its own package set is what lets the fetch run at all.

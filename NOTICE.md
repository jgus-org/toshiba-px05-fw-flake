# Upstream and distributed artifacts

| Artifact                                                                                                                                               | Licence & Notifications                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| This flake: the Nix, `extract.py`, `px05-flash.sh`, these documents                                                                                    | [MIT](LICENSE.md)                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Dell `SAS-Drive_Firmware_1DJXX_LN_AS10_A00_01.BIN` — the AS10 (`1DJXX`, A00, released 2019-09-17) DUP, the only public source of AS10 for these drives | Toshiba's drive firmware as repackaged by Dell, fetched from `dl.dell.com`. The fetched file carries Dell's proprietary banner — supplied under a Dell licence or non-disclosure agreement, not to be copied or disclosed except under it — and the release notes inside it call the package a Dell-and-third-party aggregate whose terms are designated per component, designating none for the drive image; this flake declares the fetched file `unfree` |
| `AS10_PX05.bin` — the microcode `extract.py` carves from that DUP, validated against a pinned sha256                                                   | The vendor image itself, carved out from under that banner: the carve and the validation are ours, the bytes are not, so this flake declares it `unfree` too                                                                                                                                                                                                                                                                                                |
| `sg3_utils`, `util-linux`, `coreutils`, `gnugrep` and the rest of the runtime closure                                                                  | As nixpkgs records each one in `meta.license` at the revision this flake locks, where `free` and `redistributable` are separate properties                                                                                                                                                                                                                                                                                                                  |

Nothing vendor-authored is committed here: the DUP is fetched from Dell when `packages.<system>.dup` is built, so evaluating or promoting this repository conveys nothing. Publishing a built `dup` or `firmware` output to a binary cache does convey the vendor image to whoever can read that cache. `dup` and `firmware` are the two artifacts declared `unfree`, and the flake grants `allowUnfree` in its own package set because the target it publishes — the `px05-flash` executable, which embeds the carved image as its default — is built here, so no consumer package set is left to make that choice.
